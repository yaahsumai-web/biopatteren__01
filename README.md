# Warehouse Management AI Chatbot

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Create `.env` from `.env.example`.
4. Put your Gemini API key in `.env`.
5. Open Terminal in this folder.
6. Run: `pip install -r requirements.txt`
7. Run: `python app.py`
8. Open: http://127.0.0.1:5000

Demo data is in `warehouse_data.json`. Firebase is kept for a later setup.
